Stock Monitoring & Data Storytelling

A volatility-alert pipeline and D3 data story for NVDA, TSLA and SPY.

Alert data story →

Which stock should a risk manager review each day? An interactive grid compares 3% and 5% daily-swing alert thresholds over 30 trading days.

D3 v7 · static, runs anywhere

Live price tracker →

Polls a local Python server for the latest daily closes and appends each refresh to a history table.

Needs python stock_server.py and a Massive API key

How the pieces fit

  1. Airflow pipeline fetches 30 trading days of prices from Yahoo Finance, computes returns, daily swings and alerts, and writes the CSVs the story page reads.
  2. Spark streaming ingest replays 1-minute bars in 5-minute pulls, removes overlapping rows with an anti-join, and keeps 30-minute moving averages.
  3. D3 story and live tracker present the results.
